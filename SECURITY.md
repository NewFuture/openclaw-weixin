# Security Policy

## Supported versions

Security fixes are provided for the latest 2.x release. Upgrade to the latest
published version before reporting an issue that may already be fixed.

## Reporting a vulnerability

This is a private repository, so GitHub's private vulnerability reporting
feature is unavailable. Do not open a regular GitHub issue for a suspected
vulnerability. Contact the repository administrator through an established
private channel and initially include only:

- the affected plugin and OpenClaw versions;
- a brief description of the expected impact; and
- a request for a secure channel where reproduction details can be shared.

Share proof-of-concept code, credentials, account identifiers, QR codes, or
private message content only after the administrator confirms an appropriate
private channel.

Repository administrators should track confirmed reports in a
[draft repository security advisory][advisory].

[advisory]: https://github.com/NewFuture/openclaw-wechat/security/advisories/new
